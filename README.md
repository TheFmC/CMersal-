# مرسال — التطبيق والتحديثات

## تحميل التطبيق
حمّل آخر نسخة من هنا: **[Mersal.apk](https://github.com/TheFmC/CMersal-/raw/main/Mersal.apk)**

يعمل على الجوال وعلى شاشات أندرويد TV. بعد التثبيت ادخل اسمك وكلمة المرور اللي أعطاك إياها صاحب المكتبة.

## التحديثات
التطبيق يتحقق من هذه الصفحة تلقائيًا ويرسل لك إشعار إذا نزل تحديث جديد، وتقدر تتحقق بنفسك من: الإعدادات ← التحديثات.

### لصاحب المكتبة: نشر تحديث جديد
1. ارفع رقم الإصدار في `android-native/app/build.gradle.kts` (`versionCode` و `versionName`).
2. ابنِ التطبيق، وضع الملف في `apks/Mersal-<الإصدار>.apk` وانسخه أيضًا باسم `Mersal.apk`.
3. عدّل `latest.json`: رقم الإصدار، وما الجديد، ومسار الملف.
